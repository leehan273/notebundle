# Notebundle Example

Example Notebundle note.

**Notebundle doesn't affect content. All content is handled "as-is" by the application (in this case, Markdown editors) that uses it.**

Content example:

```markdown
![sample image](./attachments/sample.svg)

Excepteur sint occaecat cupidatat non proident, sunt in culpa qui officia deserunt mollit anim id est laborum.
